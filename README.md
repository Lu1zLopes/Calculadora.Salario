## Como publicar no GitHub Pages (passo a passo)
1. Crie um novo repositório público no GitHub (ex.: `calculadora-professores-ms`).
2. Envie os arquivos `index.html` e `.nojekyll` para o branch `main`.
3. No repositório, acesse **Settings > Pages**.
4. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
5. Escolha o branch **main** e a pasta **/ (root)** e clique em **Save**.
6. Em cerca de 1 minuto o site ficará disponível no endereço `https://SEU-USUARIO.github.io/calculadora-professores-ms/`.
